Set up
Roblox Studio

Before writing any code you need somewhere to run it.

Roblox Studio is the free program every Roblox game is built in, and it is where every script in this course will run.

This lesson is only setup. By the end you will have run one script and seen it talk back to you, which is the whole loop the rest of the course is built on.

01Get Studio

Roblox Studio runs on Windows and Mac. It does not run on phones, tablets or Chromebooks.

script.lua
print("Hello world!")
OUTPUT
Hello world!  -  Server - Script:1

print means show this in the Output window. It is how a script talks to you, and you will use it in every single lesson.

“The grey part on the right is Studio telling you where the message came from.”

02The two windows you need

Studio has a lot of windows. For now you need two of them: Explorer, a list of everything in your game, and Output, where your scripts talk back to you.
